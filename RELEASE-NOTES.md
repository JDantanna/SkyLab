SkyLab 0.2 — internal revision 1.

- Modular panels: drag and resize layers, grid, review, selected line, distance trimming and batch actions. Dock left, right or below the map, or float within the SkyLab workspace. Minimize, hide, reopen and reset the saved layout from Help > Panels.
- Hand tool beside Select and Cut. Hold Space to pan while editing and release it to restore the previous tool; the selection stays intact.
- Transparent home logo and a local list of the 12 most recent files. Opening a recent file reads its current contents from disk; survey contents are not stored in the recent-file list.
- Right-click selected lines to export only that selection as MIS, preserving all vertices and mission names. Duplicate names are validated before export.
- Per-user Windows MIS registration and file activation, including forwarding to an already running SkyLab. Existing explicit Windows default-app choices are respected; choose SkyLab once in Open with > Always if another app is already the default.
- Internal upgrade from 0.1 migrates the owned uninstaller and registers MIS without requiring a new setup download. Projects, shortcuts and personal files are preserved.
- Correct inverse logo in About, duplicate contributor removed, and a test-version feedback footer on every app screen and dialog.

Update inside SkyLab, or close SkyLab and run this installer. Project JSON remains at data format 3 and still reads older formats. Operational validation in the team's navigation system remains necessary before flight use.
